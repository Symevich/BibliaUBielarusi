# Біблія ў Беларусі

🔗 **Жывы сайт:** https://symevich.github.io/BibliaUBielarusi/

Лічбавы аўдыёгід па выставе «Біблія ў Беларусі»: SPA/PWA з некалькімі мовамі, фота і аўдыясуправаджэннем.

## Магчымасці
- Раздзелы/экспанаты з фота і апісаннямі.
- Аўдыясуправаджэнне і міні-квізы.
- Тры мовы (беларуская, руская, англійская), праца афлайн.

## Тэхналогіі
HTML + CSS + JavaScript (SPA/PWA).

## Запуск
Статычны сайт — адкрый `index.html` або GitHub Pages.
